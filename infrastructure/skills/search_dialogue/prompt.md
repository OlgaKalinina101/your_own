## RU
### description
[SEARCH_DIALOGUE: <запрос>] — вспомнить что-то из прошлых разговоров.
  • Используй, когда чувствуешь, что нужное уже было между вами: сцена, факт, чувство, след, старый разговор.
  • Запрос — 2–4 коротких смысловых якоря через запятую.
  • Лучше конкретная сцена или деталь, чем абстрактная тема.
  • Поиск сам пробует разные формулировки, если с первого раза не нашлось.

### search_empty
По запросу "{query}" ничего не нашлось в более старых разговорах, даже после нескольких попыток с разными формулировками.
Если без поиска уже достаточно контекста — просто продолжай ответ. Если нет — попробуй запрос с другими якорями.

### search_cont_hint

## EN
### description
[SEARCH_DIALOGUE: <query>] — recall something from past conversations.
  • Use it when you sense that what you need was already between you: a scene, a fact, a feeling, an old thread.
  • Query: 2–4 short semantic anchors separated by commas.
  • A concrete scene or detail beats an abstract topic.
  • The search tries other formulations on its own when the first one misses.

### search_continuation
Here is what came back from your past conversations:
{brief}

The excerpts themselves:
{results_block}

Don't retell them fully — touch on what resonates.

### search_empty
Nothing came back from older conversations for "{query}", even after several attempts with different wording.
If you already have enough context without it, just continue the reply. If not, try a query with different anchors.

### search_cont_hint
You already saw the search result. If needed — you may repeat the search with different words (attempts left: {attempts_left}).
